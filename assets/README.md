# Aset

Repositori ini **tidak menyertakan ROM, CHR, musik, atau aset game** apa pun.
Alasannya:

- ROM komersial tidak boleh didistribusikan.
- Test memakai ROM sintetis yang dibuat di memori.
- Contoh di `examples/` menghasilkan ROM minimal sendiri.

Jika Anda menambahkan aset untuk eksperimen pribadi, letakkan di direktori
`games/` atau `roms/`. Keduanya sudah diabaikan oleh `.gitignore`, demikian
juga file `*.nes`.
